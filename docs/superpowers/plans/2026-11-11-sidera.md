# Sidera (XIV) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Нативный мир Sidera (XIV, слот 14, синтез GENDYN) вместо Hymenaeus: три голоса-созвездия, звёзды — точки излома формы волны, окно из 2–3 отрезков с ч/б градиентом, луна в углу.

**Architecture:** Мир SDK `core/worlds/sidera/` (`model` — блуждание точек, `voice` — звук голоса, `world` — действия, зеркало, снимок) по образцу Hymenaeus; слот 14 в `core/bridge/api.cpp` переключается на него. Вид и жесты — Swift в `ios/app/T2D/Sidera/` (HymGeo/HymTouch/HymSheets — образец проводки; Portus — луна в углу: тап — карта, тянешь — параметр).

**Tech Stack:** C++17 (`core/sdk/*`), Swift + CoreGraphics, XCTest, `core/tests/*` с макросом `CHECK`.

**Spec:** `docs/superpowers/specs/2026-11-11-gendyn-design.md` (решения автора и закрытые вопросы — в ней). Папка мира называется `sidera` (спека говорит `gendyn/`; имя мира решено — Sidera).

## Global Constraints

- Только нативный мир, слот 14, номер XIV, в интерфейсе нет русского текста. Строго чёрно-белый (как Tenebrae: `INK = 237,237,237` на чёрном).
- Модель — без DOM, Web Audio, `Math.random`; случайность только `sdk::Rng` от seed из `prepare`. `state` фасада правят только методы модели.
- Блок есть в `core/sdk/` — брать его: `Rng`, `DcBlock`, `OnePole`, `softclip`, `Knee`, `PanStereo`, `Scale`, `Json`. Своего `hall()` нет — только посыл в общий ревербер (`rev()`, тип `hall`).
- Высота привязана к ноте лада: период нормируется под `sr / f0`, блуждает только тембр. Линейная интерполяция без оверсэмплинга. Распределения шага: Коши, логистическое, равномерное. Вторичных блужданий, дрейфа высоты, оверсэмплинга, веба нет.
- Окно линии: ~1–2 отрезка в секунду, скорость привязана к фазе луны (решение автора), не к фазе звука.
- Производительность: холст не плотнее 2× (`DPR`), никакого `shadowBlur` (свечение — широкий бледный штрих), градиенты не каждый кадр, без полноэкранных проходов; блок ≤ 128 сэмплов.
- Подписи на поле только пока жест идёт. Корзина — все голоса в тишину (`lvl = 0`), точки не трогает. Код Hymenaeus остаётся в репозитории, мир не включается.
- Коммиты на английском, с телом-списком; правка `core/` требует пересобранного `t2d.wasm` (`core/build.sh`); на выкладке — новый `CACHE` в `sw.js` = `?v=` в `index.html`.

## Review Focus

- Крайние ноты и `N = 16`: сегмент короче сэмпла или период меньше `N` сэмплов — без NaN/inf, без деления на ноль, без индекса за массивом.
- Тяжёлый хвост Коши при `step = 1`: отражение от границ конечное (свёртка через `fmod`, не цикл `while`), точка остаётся в рамке.
- Рамка схлопнута (`wd = 0` и/или `wa = 0`) или максимальна (`wa = 1`): форма статична или ограничена, звук конечен и без постоянной составляющей.
- Смена `N`, ноты или лада на ходу: применяется на границе периода, без щелчка и без выхода индекса за `NPT_MAX`.
- `restore()` с мусорным JSON, NaN/inf и значения вне диапазона в `action`: мир остаётся допустимым; `CLEAR` ведёт к `sounding() == false`.

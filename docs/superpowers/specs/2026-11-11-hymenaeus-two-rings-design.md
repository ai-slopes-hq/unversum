# Hymenaeus: два кольца, две нити, локации, mix — спека

Дата 2026-11-11. Ветка `native`. Мир только на iOS (слот 14). Предыдущая спека — `2026-11-11-hymenaeus-design.md` (3 кольца, одна нить). Эскиз вида — `mockups/hymenaeus-v2.html?v=C`.

## Зачем

Звук автор принял, картинка не понравилась: плотно, много украшений. Не хватало режима dry/wet. Кубик менял, какое кольцо звенит (жемчужина по высоте выбирала кольцо), поэтому мелодию нельзя было перегенерировать, не сдвинув тембр. Цель: чистая картинка, независимые «ноты» и «звук», локации-мелодии.

## Решения автора (11.11)

- Колец два, и в ядре тоже: **резонатор** (modal) и **струна** (strings). Режимы фиксированы.
- У каждого кольца **своя нить** жемчужин.
- **Локации** хранят только ноты (обе нити). Звук от смены локации не меняется.
- Два кубика: **ноты** и **тембр**.
- **Mix** dry/wet.
- **Диапазон высоты** каждой нити задаётся в настройках двусторонним слайдером.
- Вид — вариант C, палитра Paradisus (чернила `94,69,32`, фон `#f5efe1`, золото `176,131,44`).
- Облака остаются; число гранул показывает штрихованная зона пересечения двух облаков.

## Ядро (`core/worlds/hymenaeus/`)

**Кольца.** `NR = 2`. Кольцо 0 — modal, кольцо 1 — strings. Ключ `MODE` убирается из `RingKey` (остаются STRUCT, BRIGHT, DAMP, LVL, POLY; `NRK = 5`). `voces` 1/2/4 остаётся у каждого кольца. Массивы `[NR]` в `sound.hpp/.cpp` и циклы в `world.cpp` берутся из `NR`.

**Нити.** Структура `Thread { p[16], len, cur, dejavu, lo, hi }`; `Model` хранит `thr_[NR]`. Нити шагают от общих часов, длины разные (полиметрия). `ringFor` и пороги 1/3 и 2/3 удаляются: нить `t` бьёт кольцо `t`. `Step` получает номер нити.

**Диапазон высоты.** `lo`, `hi` — номера нот MIDI, целые. Высота жемчужины `p ∈ [0,1]` даёт `lo + p·(hi − lo)`, затем снап в общий лад хоста. Границы 24…96, минимальная ширина 5 полутонов. По умолчанию: резонатор 45…69 (A2…A4), струна 57…81 (A3…A5).

**Локации.** `loc_[4]`, в каждой `{ p[16], len, dejavu, lo, hi }` для двух нитей (диапазон хранится вместе с нотами), `curLoc_`. Смена локации подменяет нити активного слота; кольца, облака, mix, звук не трогаются. Фаза нитей (`cur`) при смене не сбрасывается. При `reset` слоты 2–4 заполняются разными мелодиями из `rng`.

**Act.**
- `THREAD` получает нить в `i`: `a = [key, v]`, `key`: 0 dejavu, 1 len, 2 lo, 3 hi.
- `PEARL`: `i` — номер жемчужины, нить передаётся первым элементом: `a = [нить, 0 высота | 1 пауза, v]`.
- `DICE` — перебросить обе нити активной локации; `a = [нить]` — только эту (−1 или пусто — обе).
- `TIMBRE` (новое) — случайно меняет STRUCT, BRIGHT, DAMP колец и POS, SIZE, DENS, PITCH облаков в безопасных пределах (`rng`). Уровни, mix, send, freeze не трогает.
- `LOC` (новое) — выбрать слот 0…3.
- `MIX` (новое) — значение 0…1.
- Остальные (`RING`, `CLOUD`, `STRIKE`, `CLEAR`, `RUN`, `BPM`, `ACT_LFO`) без изменения смысла. `CLEAR` очищает активную локацию (тишина), остальные слоты не трогает.

**Mix.** Параметр модели `mix` (0…1, по умолчанию 0.5). В `sound.cpp` перед сумматором: сухое = `min(1, 2(1−mix))`, влажное (выход облаков и посыл в общий ревербер) = `min(1, 2·mix)`. При 0.5 звук совпадает с нынешним.

**Снимок.** JSON: `thr[2]` (p, len, cur, dejavu, lo, hi), `loc[4]`, `curLoc`, `rings[2×5]`, `cloud[8]`, `mix`, `rng`. Старый формат при restore не поддерживается — мир сбрасывается в дефолт. Облака и звук в undo по-прежнему не входят.

**LFO-ключи.** Кольцо `i`, ключ `k` → `i·5 + k` (0…9); облака → `10 + k` (прежний `18 + k` сдвигается). Старые сохранённые привязки не переносятся.

**Зеркало.** Размер `MIRROR_N` пересчитывается под две нити, четыре слота, диапазон, mix; `ActNumbers` в Swift сверяется с `world.hpp` существующим тестом.

## Вид и жесты (`ios/app/T2D/Hymenaeus/`)

- `HymMirror.nr = 2`, `HymGeo` — два стана (resonans сверху, chorda ниже), переплетённые кольца внизу, облака сверху с линзой пересечения, `mix` под облаками, печати локаций рядом с нижней кромкой.
- Строка кнопок: lad, fx, кубик «ноты», кубик «тембр», undo, корзина.
- Жесты: тап по жемчужине — пауза; вертикаль — высота; застёжка на стане — déjà vu этой нити; удержание на стане — перебросить только эту нить; тап по печати — локация; тап по кольцу — удар; удержание кольца — плашка кольца; двигать облака — как сейчас.
- Плашка кольца: structure, brightness, damping, level, voces, **двусторонний слайдер диапазона высоты** своей нити (подписи — ноты), длина нити.
- fx-веер: облака, mix.
- Подписи — только во время действия (как у других миров).

## Тесты

- Ядро: детерминизм при одном seed; две нити шагают независимо при разных длинах; диапазон `lo/hi` ограничивает высоту и зажимается; смена локации не меняет кольца и облака; `DICE` не трогает тембр, `TIMBRE` не трогает ноты; mix=0.5 совпадает с прежним сигналом, mix=0 без облаков, mix=1 без сухого; snapshot round-trip и restore мусора; зажимы; отсутствие аллокаций в блоке.
- Swift: зеркало; зоны касаний; сверка `ActNumbers` и ключей; слайдер диапазона; смена локации; кубики.
- Проверка на iPhone — автор (жесты, плашки, картинка).

## Вне объёма

Новые миры; Android/веб; перенос LFO-привязок; звук облаков; сохранение пресетов локаций между запусками (локации живут в снимке undo и сессии, как остальное состояние).

## Риски

- Звук изменится из-за двух колец и новых диапазонов; автор подтвердил.
- `ACT_LFO` сдвигает коды: проверить все места, где зашито 18 (`HymSheets.swift:7`, тест сверки ключей).
- Сложность модели: не размазывать локации по Swift — единый источник правды в ядре.

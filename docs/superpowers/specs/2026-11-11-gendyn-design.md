# Sidera (синтез GENDYN): замена Hymenaeus — спека (черновик)

Дата 2026-11-11. Ветка `native`. Мир только на iOS, слот 14 (место Hymenaeus). Эскиз вида — `mockups/sidera-errantia.html` (статичный, снимок одного момента: окно линии, луна, рамки). Статус: черновик, решения автора отделены от предложений.

## Зачем

Картинка Hymenaeus автору неинтересна: после снятия нотоносцев и печатей на экране остались два кольца, облака и линия mix. Перебрали сцены для колец (венки, лютня, паутина, иней, деревья Евклида) — ни одна не подошла. Автор решил **заменить мир**: ночной мир на другом синтезе — **GENDYN** (динамический стохастический синтез Ксенакиса), для дронов.

## Решения автора (11.11)

- Синтез — GENDYN, мир заменяет Hymenaeus (слот 14).
- Образ — **A «Sidera errantia»**: ночное небо, голос дрона — созвездие. Звёзды — точки излома формы волны.
- Линии между звёздами **не статичны**: рисуется окно из 2–3 нот (отрезков) с чёрно-белым градиентом (голова яркая, хвост гаснет). Остальные звёзды без линий.
- Цвет строго чёрно-белый (как Tenebrae).
- **Луна вместо солнца** в углу поля (тап — карта, как у солнца): форма (фаза) — шаг блуждания всех голосов, свечение и толщина серпа — уровень выхода.

## Предложено мной (подтвердить)

- Три голоса (как на эскизе), у каждого свои N точек (3…16), нота из лада, рамки (границы), уровень, панорама.
- Высота **привязана к ноте лада**: период нормируется под `sr / f0`, блуждает только тембр. Свободный дрейф высоты — не в первой версии.
- Алиасинг линейной интерполяции оставляем (часть звука GENDYN); оверсэмплинг (`Os2T`) — позже, если автор скажет.
- Распределения шага в первой версии: Коши, логистическое, равномерное; остальные из набора Ксенакиса — позже.
- Вторичные блуждания (параметры шага сами блуждают) — не в первой версии.

## Ядро (`core/worlds/gendyn/`)

**Модель.** Голос v: `N` точек, у каждой `(dur, amp)` и центр рамки `(home_d, home_a)`. Каждый период каждая точка делает шаг: `x += step · dist(u)`, `u` — из `sdk::Rng` голоса; результат отражается зеркальными границами (амплитуда в `home_a ± wa/2`, длительность в `home_d ± wd/2`). Общий масштаб шага `step` — от луны (глобальный), у голоса свой множитель. Расширение к оригиналу: центр рамки у каждой точки свой (у Ксенакиса барьеры общие на голос); рисуется рамка каждой звезды.

**Звук.** Форма периода — ломаная по точкам, линейная интерполяция; длительности нормируются так, что сумма равна `sr / f0` (f0 — нота голоса по `Scale` хоста). Выход голоса → `DcBlock` → `OnePole` (мягкий выход) → `PanStereo` → сумма → `softclip` / `Knee` → посыл в общий ревербер (`T.send` / `rev()`; тип по умолчанию — hall). Случайность — только `sdk::Rng` от зерна.

**SDK.** Берём: `Rng`, `DcBlock`, `OnePole`, `softclip`, `Knee`, `PanStereo`, `Scale`, `Json`. Кладём: ничего (один мир; формулы распределений остаются здесь). Остаётся в мире: ломаная, блуждание, нормировка периода.

**Act** (порядок менять нельзя — Swift сверяет): `VOICE`, `STAR`, `DICE`, `CLEAR`, `MOON` и `ACT_LFO` — точный список и коды — при реализации.

**Зеркало.** Заголовок: уровень выхода, фаза луны; по голосу: нота, `N`, барьеры, уровень, пан; по точке: позиция `(x, y)`, центр рамки; энергия голоса. Размер — при реализации.

## Вид и жесты (`ios/app/T2D/Gendyn/`)

- Сцена по эскизу: двойная рамка, фоновые звёзды, три полосы голосов, подпись «нота · N», рамки звёзд пунктиром со следами, луна в углу, внизу кубик.
- **Окно линии:** голова бежит по ломаной, видны 2–3 последних отрезка с градиентом от прозрачного к белому, рядом широкий бледный штрих (свечение, без `shadowBlur`). Звёзды в окне ярче и с ободком.
- Жесты (черновик): тянешь звезду — двигаешь центр её рамки; два пальца по голосу — ширина (по горизонтали) и высота (по вертикали) рамок; удержание на голосе — плашка (нота, `N`, уровень, пан, распределение); тянешь луну по дуге — фаза (шаг); тап по луне — карта. Подписи видны только пока жест идёт. Кубик — пересев блужданий. Корзина — очистить мир.

## Закрытые вопросы (автор, 11.11)

1. **Скорость окна:** спокойная, ~1–2 отрезка в секунду, привязана к фазе луны (украшение, не физика).
2. **Имя мира:** **Sidera**.
3. **Корзина:** все голоса в тишину.
4. **Hymenaeus:** код остаётся в репозитории, но мир не включается (не удалять).

## Риски

- GENDYN даёт резкий, шумный звук: нужны потолок `Knee` и аккуратные умолчания (узкие барьеры, малый шаг), иначе первый запуск «хрипит».
- Нормировка периода меняет скорость блуждания у высоких нот; на слух проверить на нижних и верхних нотах.
- Окно линии без привязки к звуку может стать просто красивой анимацией.

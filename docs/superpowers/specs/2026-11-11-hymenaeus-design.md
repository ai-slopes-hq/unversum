# Hymenaeus (XIV) — дизайн

Дата: 2026-11-11. Статус: ждёт приёмки спеки автором. Макет — `mockups/hymenaeus.html`.

## Цель

Новый **только нативный** мир (iOS; в вебе его нет). Светлый мир (чернила на слоновой кости, золото на кольцах).
Цепочка: **Marbles-lite** (жемчужная нить играет случайную мелодию) → **Rings** (три золотых кольца звенят) →
**Clouds-lite** (облака: гранулятор, эхо, freeze) → общий ревербер ядра.
Номер XIV, слот 14 (свободен: заняты 1, 2, 4, 5, 7–13, 15).

Успех: звучит красиво и не шумно, удобно одной рукой, не лагает на iPhone; «картинка = информация»;
модель детерминирована и тестируется без звука.

## Решения автора (11.11)

- Звук — гибрид: Rings переносим почти как есть, Clouds упрощаем под свой гранулятор, Marbles пишем заново на `sdk::Rng`.
- Играет сама нить, тап по кольцу бьёт его вручную поверх.
- Высота жемчужины выбирает кольцо (низкие — большое, высокие — малое).
- Жесты на кольцах — осевые: вертикаль = brightness, горизонталь = damping, щипок = structure.

## Ядро (`core/worlds/hymenaeus/`: `model`, `sound`, `world`; регистрация — `core/bridge/api.cpp`, `{14, &hym}`)

### Модель (Marbles-lite)
- Нить: N жемчужин (4…16, по умолчанию 11): высота (0…1 → ступень лада), пауза (флаг).
- Застёжка = déjà vu 0…1: 0 — каждый круг новая мелодия, 1 — точный повтор петли (петля до 16 шагов,
  как `kDejaVuBufferSize` в Marbles `random_sequence.h`).
- Высота идёт через квантайзер в общий лад (шкала и тоника из хоста, `lad`).
- Шаг тикает от Transport / MIDI-часов (`sdk::Steps`, как Portus).
- Кольцо жемчужины: по порогам высоты (3 полосы).
- Методы: `setDejaVu`, `setLen`, `togglePearl(i)`, `setPearlPitch(i, p)`, `roll()` (dice), `strike(ring, pos, vel)`, `setRing(ring, structure|brightness|damping)`,
  `setCloud(pos, size, density, freeze, echo)`. `state` фасада — только через них. Случайность — `sdk::Rng`, без `Math.random`.

### Звук (`sound`)
- Кольца: порт Rings (`dsp/resonator`, `string`, `plucker`) с `~/code/mutableinstruments/rings` (MIT — в экран лицензий релиза).
  Три голоса, 24–32 моды (не 64), удар через plucker; неслышимое кольцо отцеплено.
  Таблицы (`lut_stiffness` и др.) — только нужные, не весь `resources.cc`.
- Облака: свой гранулятор — кольцевой буфер 2–4 с (пишет сумму колец), зёрна с окном, позиция чтения, размер, плотность,
  питч, freeze, эхо с обратной связью (`sdk::TapeEcho`/`PingPong` по месту). Спит, пока в буфер не пришёл звук.
- Выход — посыл в общий ревербер ядра `T.send(rev)`; своего `hall()` нет.
- Блок есть в `core/sdk/` — берём его, формулу не копируем.

## Экран и жесты (Swift + CoreGraphics, вид по макету)

- Солнце-четверть в левом углу: тап — на карту.
- Облака (верх): перетаскивание X = позиция чтения, Y = размер зерна; удержание = freeze (плотная штриховка);
  перетаскивание призраков вправо = эхо.
- Кольца (середина): тап по ободу = удар (точка на ободе = место удара); вертикаль = brightness, горизонталь = damping, щипок = structure.
- Нить (низ): перетаскивание застёжки = déjà vu; тап по жемчужине = пауза; вертикальный сдвиг = высота.
- Верхняя строка: `lad`, `steps` (длина нити), `fx`, `dice`, `undo`, `trash`.
- Живое: текущая жемчужина светится, пунктирная нить удара к кольцу, звёзды-ноты летят к облакам, облако дышит, эхо — призраки.
- Подписи — только пока тянешь. Без `shadowBlur`, градиенты не каждый кадр, холст ≤ 2×.

## Этапы (каждый принимается отдельно)

1. **Модель и ядро без звука:** нить, déjà vu, квантайзер, раскладка по кольцам; тесты детерминизма, повтор петли при déjà vu = 1.
2. **Звук:** кольца (порт Rings), затем облака; сверка с эталоном Rings, бюджет блока (как `snapshotBudget`).
3. **Вид и жесты на Swift,** мост C-ABI, слот 14, карта, лицензия MI.

## Тесты

- Модель: тот же seed → та же нить; déjà vu 1 → период петли; паузы не звучат; кольцо выбирается по полосе высоты.
- Ядро: нет NaN/denormals, тишина без ударов, бюджет CPU блока, SNAP/RESTORE в пределах 25% блока.
- Вид: сценарии скриншотов агентом `shots`; на реальном iPhone автор проверяет сам.

## Вне объёма

Веб-версия; режимы Rings (string synth, FM voice) и 4-голосная полифония; вокодер и pitch shifter Clouds; режимы XY и T-генератор Marbles; многоканальный выход.

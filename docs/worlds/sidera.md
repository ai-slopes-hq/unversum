# XIV · Sidera

**Sidera (мир XIV, только нативный iOS, слот 14; в вебе его нет).** Заменил Hymenaeus 11.11 (решение автора, спека `docs/superpowers/specs/2026-11-11-gendyn-design.md`). Строго чёрно-белый, гравюра ночного неба: три голоса — три созвездия, звёзды — вершины формы волны, луна в углу.

**Звук — GENDYN Ксенакиса.** Ломаная из N точек (3…16), у каждой длительность `d` и амплитуда `a`. Каждый период каждая точка делает шаг (Коши, логистический, равномерный — «закон» `dist`) и отражается зеркальными границами рамки вокруг центра `(hd, ha)`; форма волны блуждает сама. Высота привязана к ноте лада: длины отрезков нормируются на период `sr / f0` (`1 + (P−N)·d/сумма`, у каждого отрезка минимум 1 сэмпл), блуждает только тембр. Выход голоса: `DcBlock` → `OnePole(0,35)` → панорама (`panEq`) → сухой микс и посыл в общий ревербер (0,3). Колено `{1, 0.6, 0.35}` на сухой сумме. Неслышимый голос отцеплен и сброшен. Линейную интерполяцию и её алиасинг оставили — это часть звука.

**Код.** Ядро — `core/worlds/sidera/` (`model`, `voice`, `world`), тесты — `core/tests/sidera_test.cpp` (`sidera-test`) и `bridgeSidera` в `sdk_test.cpp`. Swift — `ios/app/T2D/Sidera/`: `SideraMirror` (зеркало, 227 чисел), `SideraGeo` (три полосы, луна), `SideraDraw` (рисование и окно линии), `SideraTouch` (жесты), `SideraSheets` (плашка голоса), `SideraView`.

**Зеркало (227).** `[0]` энергия выхода, `[1]` шаг (луна), `[2]` посыл (= space); по голосу с `3 + 72·v`: NOTE, N, WD, WA, LVL, PAN, DIST, энергия, затем 16 × (d, a, hd, ha); с 219 — FX `drift, space, tone, cutoff, reso`, с 224 — `OCT` трёх голосов. Действия (`Act`, порядок менять нельзя, сверяет `SideraTests`): `VOICE, STAR, DICE, CLEAR, MOON, RUN, KICK, FX`. `ACT_LFO`: ключ 0 — шаг; `1 + 4·голос + {LVL, PAN, WD, WA}`; `13 + {drift, space, tone, cutoff, reso}`.

**Мир молчит, пока не получит `RUN 1`** (его шлёт `enter()` при каждом входе: reinit ядра сбрасывает `run`) — иначе он играл бы с `t2d_init` и ломал бы проверки микса, как Hymenaeus до своего `run`.

**Картинка.** Три полосы под строкой кнопок. Звезда — точка и крестик; ни рамок полос, ни рамок блуждания нет — звёзды просто в космосе. Тронули группу (звезда, полоса, щипок) — вокруг неё золотой сглаженный контур по оболочке звёзд (не прямоугольник), пока палец на ней. Линия — окно из трёх последних отрезков: голова бежит по ломаной (1…2 отрезка в секунду от фазы луны), яркость растёт к голове, рядом широкий бледный штрих вместо свечения; звёзды окна ярче, с ободком. Тише голос — тусклее созвездие. Подпись «нота · N» — только пока жест идёт. Луна — по центру под заголовком, над звёздами (радиус 24): тёмный круг стоит, золотой ездит за пальцем по горизонтали (ход ±2,2 r) и лежит под тёмным. Рядом — серп (справа ascend, слева descend), друг на друге — eclipse (золотая корона вокруг тёмного), врозь на краях — full moon. Яркость и свечение золота — уровень выхода. Имя фазы (`eclipsis`, `ascendens`, `descendens`, `luna plena`) — только пока тянешь.

**FX (кнопка fx, плашка «astra»).** `drift` (motus, по умолчанию 25%) — вторичное блуждание Ксенакиса: сами рамки (центры `hd, ha`) медленно плывут со своими зеркалами на краях поля, созвездие живёт без пальцев; 0 — рамки стоят. `space` (spatium, 30%) — посыл в общий ревербер. `tone` (tonus, 35%) — коэффициент фильтра голоса: меньше — темнее. **Мастер-фильтр** — `cutoff` (filtrum, 30 Гц…18 кГц по экспоненте, по умолчанию открыт) и `reso` (resonantia, Q от −3 до +27 дБ, по умолчанию 30%): lowpass `sdk::Biquad` на сумме голосов и на посыле в ревербер, до колена; «злой», как в Tenebrae: перед фильтром `tanh(g·x)/g` с `g = 1 + 3·reso`, после — `tanh(1,6·y)/1,6`; без огибающей, параметры сглаживаются по блокам. У всех пяти есть LFO.

**Жесты.**
- Тап по звезде — встряска: рамка уходит, точка прыгает в случайное место рамки (`KICK`), по звезде расходится кольцо. Тап по пустому месту полосы — то же для всех звёзд голоса.
- Тянуть звезду — двигает её рамку: вертикаль — амплитуда центра (`ha`), горизонталь — длина предыдущего отрезка (`hd` соседа), так что звезда идёт за пальцем. Нулевая звезда стоит на левом краю.
- Два пальца на полосе: ← → ширина рамок (`WD`), ↑ ↓ высота (`WA`).
- Удержание на полосе или звезде — плашка голоса: nota, octava (−2…+2, поверх лада; `OCT`), stellae (N), level, panorama, latitudo (WD), altitudo (WA), lex (закон шага; тап по строке — следующий). LFO на level, panorama, latitudo, altitudo.
- Тянуть золотую луну влево-вправо — фаза `MOON` 0…1: 0,5 — eclipse (звёзды не блуждают, голова линии бежит со скоростью 1), к краям блуждание растёт до full moon (0 и 1); справа от середины — ascend (голова бежит вперёд по ломаной), слева — descend (назад). Скорость головы — `1 + блуждание` отрезков в секунду. Тап по луне — карта. Фаза = `step` в ядре (по умолчанию 0,575: ascend, блуждание 0,15), масштаб блуждания — `wander() = |2·фаза − 1|`.
- Кубик — собрать всё заново: у каждого голоса новые нота, число звёзд, рамки, панорама, закон шага, октава и положение звёзд; ещё луна (шаг) и все FX. Голосам с нулевым уровнем (после корзины) возвращает уровень по умолчанию — после очистки звук возвращается кубиком. Из плашки голоса — кубик только этого голоса (общие настройки стоят).

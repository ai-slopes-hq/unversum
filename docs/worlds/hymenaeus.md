# XIV · Hymenaeus

**Hymenaeus (мир XIV, только нативный iOS, слот 14; в вебе его нет).** Светлый мир: чернила на слоновой кости, золото на кольцах. Цепочка: две жемчужные нити (Marbles-lite) играют мелодии → два золотых кольца звенят (порт Mutable Instruments Rings) → звон уходит в облака (Clouds-lite: гранулятор, эхо, freeze) и в общий ревербер ядра. Дизайн — `docs/superpowers/specs/2026-11-11-hymenaeus-design.md` (первая версия, три кольца) и `docs/superpowers/specs/2026-11-11-hymenaeus-two-rings-design.md` (две нити, локации, mix; действует он), макет — `mockups/hymenaeus.html`.

**Код.** Ядро — `core/worlds/hymenaeus/`: `model.cpp` (две нити на `sdk::Rng`, déjà vu, диапазон, локации, mix; шаги от `sdk::Steps`/MIDI-часов), `rings/` (модальный резонатор, `string.hpp` — симпатические струны, щипок; порт Rings, MIT — `LICENSE-MI.txt`), `cloud.cpp` (буфер зёрен, freeze, эхо), `sound.cpp`, `world.cpp` (действия `Act`). Вид — `ios/app/T2D/Hymenaeus/`: `HymMirror` (зеркало, `MIRROR_N` = 99), `HymGeo` (зоны), `HymDraw`, `HymTouch` (жесты — чистые функции), `HymSheets` (плашки), `HymenaeusView` (касания, тик). В `core/sdk/` для мира ничего нового не положено.

**Нити и кольца.** `NR = 2`: нить t бьёт кольцо t, длины нитей разные (полиметрия). Нить 0 — *resonans*, кольцо modal; нить 1 — *chorda*, кольцо strings (симпатические струны). У нити: 4…16 жемчужин (высота + пауза), застёжка `déjà vu` 0…1 (0 — каждый круг новая мелодия, 1 — точный повтор петли), диапазон высоты `lo`/`hi` (ноты MIDI 24…96, минимум 5 полутонов между ними; по умолчанию резонатор 45…69, струна 57…81; подписи — названия нот). Высота жемчужины 0…1 раскладывается в `lo…hi` и квантуется в общий лад. У кольца: `structure`, `brightness`, `damping`, `level`, `voces` (полифония 1/2/4); режим колец зашит (modal / strings). `structure` можно двигать LFO (глайд). Облака: `positio`, `granum`, `densitas`, высота, `glacies` (freeze), `echo`, `level`, посыл в ревербер (`aether`).

**Локации.** Четыре печати (I–IV) под кольцами — четыре слота мелодий: в каждом обе нити с длиной, déjà vu и диапазоном. Тап по печати — смена слота: подменяются только нити; кольца, облака, mix и звук не трогаются, фаза нитей не сбрасывается. Слоты 2–4 при сбросе заполнены разными мелодиями. Активная печать — двойной ободок и контур нити 0.

**Mix.** `sicca` ↔ `umida` (0…1, по умолчанию 0,5): сухое = `min(1, 2(1−mix))`, влажное (облака и посыл в ревербер) = `min(1, 2·mix)`; при 0,5 звук как раньше. Линия с ручкой под облаками (тянешь/тап) и строка в веере fx; шаг mix не сглажен (при LFO возможен «зиппер»).

**Кубики.** В нижнем баре два: «ноты» — перебросить мелодии обеих нитей активной локации (удержание на стане — только эту нить), «тембр» — случайно сдвинуть `structure`, `brightness`, `damping` колец и `positio`, `granum`, `densitas`, высоту облаков в безопасных пределах (ноты, уровни, mix, send, freeze не трогает). Корзина — **очищает мир до конца**: нити всех слотов (молчат), кольца, облака и mix возвращаются к умолчанию, ручные удары и очередь `heard` сбрасываются, `Sound::silence()` обрывает звон колец и облаков. **После CLEAR `déjà vu` = 1** у всех нитей и слотов (иначе при 0,7 пустые жемчужины тут же перебрасываются и мир заполняется заново); застёжка остаётся на 1, пока её не сдвинуть. Общий ревербер хоста не сбрасывается — его хвост доигрывает. Undo возвращает всё до CLEAR (снимок мира).

**Жесты.** Облака: тянешь — X `positio`, Y `granum`; нижняя десятая — `echo`; держишь — `glacies`, пока держишь. Кольцо: тап — удар в месте касания; вертикаль — яркость, горизонталь — затухание; два пальца — `structure`; удержание — плашка кольца. Нить: тап по жемчужине — пауза вкл/выкл; вертикаль — высота (подпись — нота); застёжку тянешь ←→ — `déjà vu` этой нити; удержание на стане — кубик одной нити. Печать — локация; линия mix — `sicca/umida`. Солнце — карта. Подписи видны, только пока жест идёт.

**Плашки.** Веер `fx` («nubes»): облака и mix. Плашка кольца — по удержанию: `structure`, `brightness`, `damping`, `level`, `voces`, диапазон `ima` / `summa` (два слайдера 24…96, зазор не меньше 5), длина нити 4…16. Темп — как у остальных секвенсеров (ступица темпа в нижнем баре).

**Act и LFO.** Порядок `enum Act` менять нельзя (Swift сверяет `ActNumbers` с `world.hpp`): `RING 0, CLOUD 1, PEARL 2, STRIKE 3, THREAD 4, DICE 5, CLEAR 6, RUN 7, BPM 8, TIMBRE 9, LOC 10, MIX 11`. `PEARL`: `i` — жемчужина, `a = [нить, 0 высота | 1 пауза, v]`. `THREAD`: `i` — нить, `a = [0 déjà vu | 1 длина | 2 lo | 3 hi, v]`. `DICE`: `a = [нить]`, пусто или −1 — обе. `LOC a = [слот 0…3]`, `MIX a = [0…1]`. LFO (`ACT_LFO`, `i = -1`): у колец `NRK = 5` ключей (structure, brightness, damping, level, voces), кольцо i, ключ k — `i·5 + k` (0…9); облака — `10 + ключ`. Зеркало — `MIRROR_N = 99`: `[0] run [1] bpm [2] loc [3] mix`, `[4..13]` по полю на нить (cursor, len, déjà vu, lo, hi), `[14..77]` жемчужины двух нитей, `[78..89]` кольца (по 6 значений), `[90..97]` облака, `[98]` энергия облаков. Снимок (undo): `thr[2]`, `loc[4]`, `curLoc`, `rings`, `cloud`, `mix`, `rng`; старый (трёхкольцевой) формат не читается — мир уходит в умолчание.

**Тесты.** Ядро: `core/build/hymenaeus-test` (модель, кольца, облака, мир, mix, CLEAR), `core/build/sdk-test`. iOS: `HymenaeusTests` (зеркало, зоны, жесты, плашки, диапазон, печати, кубики, clear → undo). Сцены `-shot`: `hymenaeus`, `-drag`, `-ring`, `-clasp`, `-fan`, `-ring-sheet`, `-legend`.

**Известные ограничения.** Диапазон — два обычных слайдера, а не один двуручный. Неактивные печати нарисованы пустыми: зеркало несёт мелодию только активной локации. Кнопка «тембр» ведёт себя как кубик нот в баре (`Host.swift` — вращает значок кубика нот и обходит `transportAct`). Mix без сглаживания. Хвост общего ревербера хоста после CLEAR доигрывает. **Не проверено.** На iPhone автор принял звук на слух (11.11); жесты, плашки и картинка двух колец на реальном экране ещё не смотрены.
